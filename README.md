# RoamWise — AI Atmospheric Travel Planner

RoamWise is an intelligent mobile travel companion that adapts day-by-day itineraries dynamically to live weather forecasts and unexpected schedule shifts.

Designed in **Google Stitch**, built with **React, Vite, TypeScript, Tailwind CSS**, and a **Python Flask + SQLite** backend.

---

## Project Structure
- `frontend/`: React 18, Vite, TypeScript, Tailwind CSS with Stitch design tokens.
- `backend/`: Flask REST API, SQLite database, routes for trips, weather, and alerts.
- `design-reference/`: Google Stitch `DESIGN.md` tokens, 11 downloaded HTML screen references, and manifest.
- `documentation/`: Architecture overview and setup guides.
